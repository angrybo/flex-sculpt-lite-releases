# Flex Sculpt Lite — Downloads

3D sculpting for print, for Windows.

## Download

Get the latest installer from **[Releases](https://github.com/angrybo/flex-sculpt-lite-releases/releases/latest)** — download `Flex-Sculpt-Lite-Setup-<version>.exe` and double-click it.

If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**.

## Updates

Already installed? You don't need to download again: Flex Sculpt Lite checks for new versions by itself and shows **Update available** inside the app. Click **Download**, then **Restart & install**.

You can also check any time from the **Interface** menu (sliders icon, top right) → **Check for updates**.
